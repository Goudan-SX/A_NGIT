# Guardian-AI 客户端安装说明

这是普通用户使用的轻量客户端，不安装 Python、SQL Server 或后端。

## 安装

1. 解压客户端安装包。
2. 双击 **Client-Setup.bat**。
3. 安装目录默认：`D:\Guardian-AI\client`，可点“浏览…”修改。
4. 服务器地址已预填管理员提供的稳定地址；如不一致请手动修改。
5. 点击“开始安装”，会创建桌面/开始菜单 **Guardian-AI** 快捷方式。

## 登录

- 双击桌面 Guardian-AI，以应用窗口打开中心网页。
- 使用 **邮箱 + 密码 + 统一访问密钥** 登录/注册。
- 访问密钥由管理员提供；普通用户最多 7 个，每用户 1GB。
- 用户名必须是邮箱格式。

## 数据说明

- 客户端不保存本地数据库，所有账号、检测、上传数据都写入中心服务器。
- 普通用户可以读取科普、案例、知识库等非用户数据，但只能读写自己的用户数据。
- 服务器关机或隧道停止时，客户端无法使用。

## 系统要求

- Windows 10 / 11，已安装 Edge 或 Chrome。
- 服务器地址必须可访问（HTTPS）。
- 不需要管理员权限，除非安装到受保护目录。

## 卸载

删除桌面/开始菜单快捷方式和 `D:\Guardian-AI\client` 目录即可。
